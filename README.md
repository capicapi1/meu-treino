# Meu Treino — PWA

Esta é a versão web/PWA do app SwiftUI.

## O que já funciona
- Tela de boas-vindas e nome
- Cores: Azul, Amarelo, Roxo, Verde, Vermelho e Rosa
- Treinos e exercícios
- Séries/repetições/carga/descanso
- Cronômetro de descanso
- Marcação de séries concluídas
- Criar, editar e excluir treinos
- Fotos dos exercícios
- Dados salvos localmente no aparelho
- Manifest + service worker para instalação como PWA

## Importante
Para o PWA ser instalável no iPhone, ele precisa ser servido por HTTPS. Não basta abrir o `index.html` diretamente no Safari.

Uma forma gratuita de publicar é GitHub Pages ou Cloudflare Pages.

## Observação sobre dados
Cada aparelho possui seus próprios dados. Alterações feitas no seu iPhone não aparecem automaticamente no iPhone da sua amiga.
